# ChatJulia

ChatJulia is the ChatArch Julia tooling package entrypoint. The package currently keeps a minimal root-only CLI so the Julia tooling shell remains installable, discoverable, and releasable; real Julia orchestration commands are not exposed yet.

## Quick Start

```bash
pip install ChatJulia
chatjulia --help
chatjulia --version
chatjulia --tree
chatjulia --tree-brief
```

## Current CLI Tree

```text
chatjulia
├── --help  # Show this message and exit.
├── --version  # Show the version and exit.
├── --tree  # Print the registered CLI tree and exit.
└── --tree-brief  # Print the registered CLI tree without parameter signatures and exit.
```

## CLI Boundary

- The current CLI only exposes root options and has no business subcommands.
- `--tree` and `--tree-brief` are generated by ChatStyle from the real Click command registration, with the public tree root fixed to the canonical command name `chatjulia`.
- `--tree` retains parameter signatures by default; `--tree-brief` omits signatures while retaining command nodes and descriptions. Because the current CLI has only boolean root options and no parameterized subcommands, their output is presently identical.
- When real Julia environment, package, script, or execution orchestration commands are added later, update the Click registration first and then sync docs from the real `chatjulia --tree` and `chatjulia --tree-brief` outputs.

## Layout

- `src/`: package source code
- `tests/code-tests/`: code tests and migrated historical tests
- `tests/cli-tests/`: real CLI tests, doc-first
- `tests/mock-cli-tests/`: mock/fake CLI tests, doc-first
- `docs/`: long-lived project docs built by MkDocs
